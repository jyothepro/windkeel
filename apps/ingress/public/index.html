Windkeel ingress

This deployment serves exactly one endpoint: POST /api/webhook, the GitHub App webhook receiver. Anything else here is this page.

It exists so that a deploy can be confirmed live without sending a signed delivery — a GET / that returns this is the cheapest proof the project built and routed. It is also what outputDirectory points at: a project with only a function still needs a static output directory, and pointing that at the app root would publish dist/ and src/.

The endpoint's behaviour, status codes, and idempotency are documented in docs/webhook-ingress.md.
