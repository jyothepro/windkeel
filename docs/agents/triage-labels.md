# Triage labels

Skills speak of five triage roles. In this repo each label string equals the role name.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified; an AFK agent can take it |
| `ready-for-human` | Needs a person to implement |
| `wontfix` | Will not be actioned |

Other labels in use: `windkeel` (on an issue, starts a factory run), `wayfinder:*` (see
`issue-tracker.md`).
