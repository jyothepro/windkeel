# Architecture decision records

Each ADR leads with a short **Context / Decision / Consequences** (≤500 words). The full original
reasoning, alternatives and dated amendments follow under `## Background` in the same file; the
`§n` numbers that code comments cite resolve in both parts. Fully superseded records live in
[`archive/`](archive/). Start with [CONTEXT.md](../../CONTEXT.md) for the glossary, the invariants and the system map.

Rules that can be checked mechanically are: `npm run invariant:check`
([`scripts/invariant-check.mjs`](../../scripts/invariant-check.mjs)) and `npm run arch:check`
([`scripts/arch-check.mjs`](../../scripts/arch-check.mjs)).

Status values: **Accepted**, **Proposed** (written, not yet accepted; parts may already be built),
**Superseded by ADR-NNNN**; "amended by" lists later ADRs that change part of a record.
