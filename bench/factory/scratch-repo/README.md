# orqon-bench-scratch

A small, dependency-free library that the Orqon factory benchmark poses real-repo tasks against.
`npm test` runs `node --test`.

This repository is seeded from `bench/factory/scratch-repo/` in the Orqon repository by
`bench/factory/seed-scratch-repo.sh`. Benchmark tasks open pull requests against it; it is a
scratch repository and nothing here is used anywhere.
